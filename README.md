# Sunbeam

![Sunbeam](public/imgs/sunbeam-repo.png)

[Sunbeam](https://sunbeam.hackclub.com/) is a social coding event by [Hack Club](https://hackclub.com) for 13-18 years old girls happening in 20+ cities on Aug 29, 2026. We are a community of 140k+ technical teenagers building and shipping cool open-source projects. This program is run by the Athena Initiative of Hack Club, a community specifically for girls. 


## Event Cities
Atlanta, Auckland, Austin, Bengaluru, Berlin, Bogota, Boston, Burlington, Casablanca, Charlotte, Chicago, Columbus, Dallas, DC, Delhi, Dhaka, Dubai, Dundee, Hong Kong, Houston, Islamabad, Jakarta, Jeju, Karachi Division, Lahore, London, Los Angeles, Managua, Marrakesh, Miami, Milan, Minneapolis, New York City, Ottawa, Penang, Philadelphia, Portland, Sacramento, San Francisco, Seattle, Sydney, Tampa, Toronto, Victoria, Winnipeg
